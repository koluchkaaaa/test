# План и свет

Адаптивное клиентское приложение: услуги, интерактивный пример планировки, подбор услуг и площади, подготовка заявки.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Настройка

В `config.js` укажите `telegramUsername` без символа `@`. При пустом значении посетители могут скопировать или скачать заявку.

В `rates` укажите стоимость каждой услуги в рублях за м². Значение `null` оставляет стоимость «По запросу». Если для какой-либо выбранной услуги тариф не задан, итоговая стоимость также отображается по запросу.

Пример квартиры на сайте — иллюстрация, а не реальный клиентский проект. Замените его своими материалами перед использованием в качестве портфолио.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и сохраните.

Файлы `index.html`, `style.css`, `app.js`, `config.js`, `favicon.svg` и `.nojekyll` должны находиться в корне репозитория. Все пути относительные, поэтому сайт поддерживает размещение в подпапке репозитория.

Форма создаёт текст заявки в браузере. Она не отправляет данные на сервер. При настроенном Telegram появляется ссылка на диалог с подготовленным текстом.
